# Задание

Дайте развернутый ответ.

Найдите все значения \(a\), при которых уравнение

\[
(x + \ln(x + a))^3 = (x - \ln(x + a))^3
\]

имеет единственное решение на отрезке \([0; 1]\).

---

# Решение

## 1. Преобразование уравнения

Так как функция \(t^3\) строго монотонна, уравнение равносильно:

\[
x + \ln(x + a) = x - \ln(x + a).
\]

Переносим:

\[
\ln(x + a) + \ln(x + a) = 0 \quad \Rightarrow \quad 2\ln(x + a) = 0.
\]

Отсюда:

\[
\ln(x + a) = 0 \quad \Rightarrow \quad x + a = 1.
\]

Таким образом, исходное уравнение сводится к линейному:

\[
x = 1 - a.
\]

## 2. Условие единственности на отрезке \([0; 1]\)

Уравнение \(x = 1 - a\) имеет единственное решение на отрезке \([0; 1]\), если точка \(x = 1 - a\) принадлежит этому отрезку.

То есть:

\[
0 \le 1 - a \le 1.
\]

Решаем:

\[
0 \le 1 - a \quad \Rightarrow \quad a \le 1.
\]

\[
1 - a \le 1 \quad \Rightarrow \quad -a \le 0 \quad \Rightarrow \quad a \ge 0.
\]

Значит, \(a \in [0; 1]\).

## 3. Область определения логарифма

Логарифм \(\ln(x + a)\) определён при:

\[
x + a > 0.
\]

На отрезке \(x \in [0; 1]\) это условие должно выполняться для всех \(x\).  
Минимальное значение \(x + a\) достигается при \(x = 0\):

\[
0 + a > 0 \quad \Rightarrow \quad a > 0.
\]

## 4. Окончательный ответ

С учётом \(a > 0\) и \(a \in [0; 1]\), получаем:

\[
a \in (0; 1].
\]

---

# Ответ

\((0; 1]\)
