# Задание

Впишите правильный ответ.

Найдите корень уравнения \(\left(\frac{1}{5}\right)^{x+3} = 25\).

---

# Решение

1. Представим правую часть как степень с основанием \(\frac{1}{5}\):  
   \[
   25 = 5^2 = \left(\frac{1}{5}\right)^{-2}
   \]

2. Получаем уравнение:  
   \[
   \left(\frac{1}{5}\right)^{x+3} = \left(\frac{1}{5}\right)^{-2}
   \]

3. Так как основания равны, приравниваем показатели:  
   \[
   x + 3 = -2
   \]

4. Решаем:  
   \[
   x = -2 - 3 = -5
   \]

---

# Ответ

-5
