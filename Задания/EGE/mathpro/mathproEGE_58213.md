# Задание

Дайте развернутый ответ.

Решите неравенство

\[
\frac{15^x - 3^{x+1} - 5^{x+1} + 15}{-x^2 + 2x} \ge 0.
\]

---

# Решение

## 1. Упрощение числителя

Сгруппируем числитель:

\[
15^x - 3^{x+1} - 5^{x+1} + 15.
\]

Так как \(15^x = 3^x \cdot 5^x\), а \(3^{x+1} = 3 \cdot 3^x\), \(5^{x+1} = 5 \cdot 5^x\), перепишем:

\[
3^x \cdot 5^x - 3 \cdot 3^x - 5 \cdot 5^x + 15.
\]

Сгруппируем:

\[
3^x (5^x - 3) - 5(5^x - 3) = (5^x - 3)(3^x - 5).
\]

Проверим:

\[
(5^x - 3)(3^x - 5) = 5^x \cdot 3^x - 5 \cdot 5^x - 3 \cdot 3^x + 15 = 15^x - 5^{x+1} - 3^{x+1} + 15.
\]

Всё верно.

Значит, числитель:

\[
(5^x - 3)(3^x - 5).
\]

---

## 2. Знаменатель

\[
-x^2 + 2x = -x(x - 2) = x(2 - x).
\]

Нули знаменателя: \(x = 0\), \(x = 2\).

---

## 3. Знаки числителя

### Нули числителя:

1. \(5^x - 3 = 0 \Rightarrow 5^x = 3 \Rightarrow x = \log_5 3.\)

2. \(3^x - 5 = 0 \Rightarrow 3^x = 5 \Rightarrow x = \log_3 5.\)

Так как \(\log_5 3 \approx 0,68\), \(\log_3 5 \approx 1,46\), оба положительные.

---

## 4. Метод интервалов

Область определения: \(x \neq 0, \, x \neq 2\).

Точки, в которых числитель может менять знак:  
\(x = \log_5 3\), \(x = \log_3 5\).

Также знаменатель меняет знак в точках \(x = 0\) и \(x = 2\).

Расположим все точки на числовой прямой:

\[
0 < \log_5 3 < \log_3 5 < 2.
\]

---

## 5. Определение знаков на интервалах

Рассмотрим интервалы:

1. \(x < 0\)  
   \(5^x - 3 < 0\) (т.к. \(5^x < 1 < 3\)),  
   \(3^x - 5 < 0\) (т.к. \(3^x < 1 < 5\)).  
   Произведение двух отрицательных → числитель **положителен**.  
   Знаменатель \(x(2 - x)\): при \(x < 0\): \(x < 0\), \(2 - x > 0\) → произведение **отрицательно**.  
   Дробь: \(+ / - = -\) → **не подходит**.

2. \(0 < x < \log_5 3\)  
   Возьмём \(x = 0,5\):  
   \(5^{0,5} - 3 < 0\), \(3^{0,5} - 5 < 0\) → числитель **+**.  
   Знаменатель \(x(2 - x)\): \(x > 0\), \(2 - x > 0\) → **+**.  
   Дробь: \(+ / + = +\) → **подходит**.

3. \(\log_5 3 < x < \log_3 5\)  
   Возьмём \(x = 1\):  
   \(5^1 - 3 = 2 > 0\), \(3^1 - 5 = -2 < 0\) → числитель **−**.  
   Знаменатель: \(x > 0\), \(2 - x > 0\) → **+**.  
   Дробь: \(- / + = -\) → **не подходит**.

4. \(\log_3 5 < x < 2\)  
   Возьмём \(x = 1,8\):  
   \(5^{1,8} - 3 > 0\), \(3^{1,8} - 5 > 0\) → числитель **+**.  
   Знаменатель: \(x > 0\), \(2 - x > 0\) → **+**.  
   Дробь: \(+ / + = +\) → **подходит**.

5. \(x > 2\)  
   Возьмём \(x = 3\):  
   \(5^3 - 3 > 0\), \(3^3 - 5 > 0\) → числитель **+**.  
   Знаменатель: \(x > 0\), \(2 - x < 0\) → **−**.  
   Дробь: \(+ / - = -\) → **не подходит**.

---

## 6. Ответ

Решение:  
\[
(0; \log_5 3] \cup [\log_3 5; 2).
\]

---

# Ответ

\((0; \log_5 3] \cup [\log_3 5; 2)\)
