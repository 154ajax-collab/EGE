# Задание

Впишите правильный ответ.

Фабрика выпускает сумки. В среднем 3 сумки из 40 имеют скрытый дефект. Найдите вероятность того, что купленная сумка окажется без скрытого дефекта.

---

# Решение

1. Всего сумок: 40.
2. С дефектом: 3.
3. Без дефекта: \(40 - 3 = 37\).
4. Вероятность купить сумку без дефекта:
   \[
   P = \frac{37}{40} = 0,925
   \]

---

# Ответ

0,925
