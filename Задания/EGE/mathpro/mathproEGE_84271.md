# Задание

Впишите правильный ответ.

В среднем из 2500 садовых насосов, поступивших в продажу, 70 подтекают. Найдите вероятность того, что один случайно выбранный для контроля насос не подтекает.

---

# Решение

1. Всего насосов: 2500.
2. Подтекающих: 70.
3. Исправных:  
   \[
   2500 - 70 = 2430
   \]
4. Вероятность того, что случайно выбранный насос не подтекает:  
   \[
   P = \frac{2430}{2500} = 0,972
   \]

---

# Ответ

0,972
