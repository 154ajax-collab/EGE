# Задание

Впишите правильный ответ.

На конференцию приехали учёные из трёх стран: 5 из Австрии, 4 из Германии и 6 из Сербии. Каждый из них делает на конференции один доклад. Порядок докладов определяется жеребьёвкой. Найдите вероятность того, что десятым окажется доклад учёного из Сербии.

---

# Решение

1. Общее число участников:
   \[
   5 + 4 + 6 = 15
   \]

2. Благоприятные исходы (доклад из Сербии) — 6.

3. Вероятность того, что на любом фиксированном месте (в том числе на десятом) окажется доклад учёного из Сербии, равна отношению числа сербских участников к общему числу участников:
   \[
   P = \frac{6}{15} = \frac{2}{5} = 0,4
   \]

---

# Ответ

0,4
