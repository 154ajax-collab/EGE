# Задание

Впишите правильный ответ.

Найдите корень уравнения \((x - 4)^3 = 27\).

---

# Решение

1. Извлечём кубический корень из обеих частей:
   \[
   x - 4 = \sqrt[3]{27} = 3.
   \]

2. Решим линейное уравнение:
   \[
   x = 3 + 4 = 7.
   \]

3. Проверка (подставим в исходное уравнение):
   \[
   (7 - 4)^3 = 3^3 = 27.
   \]
   Корень подходит.

---

# Ответ

7
