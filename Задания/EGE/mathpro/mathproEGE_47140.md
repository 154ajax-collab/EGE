# Задание

Впишите правильный ответ.

Найдите корень уравнения \(3^{12 - x} = 27\).

---

# Решение

1. Представим правую часть как степень с основанием 3:
   \[
   27 = 3^3.
   \]

2. Получаем уравнение:
   \[
   3^{12 - x} = 3^3.
   \]

3. Так как основания равны, приравниваем показатели:
   \[
   12 - x = 3.
   \]

4. Решаем линейное уравнение:
   \[
   -x = 3 - 12,
   \]
   \[
   -x = -9,
   \]
   \[
   x = 9.
   \]

---

# Ответ

9
