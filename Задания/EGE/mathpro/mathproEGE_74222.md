# Задание

Впишите правильный ответ.

В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 25\), \(AC = 20\). Найдите \(\sin A\).

---

# Решение

1. В прямоугольном треугольнике \(ABC\) с прямым углом \(C\):
   - \(AB = 25\) — гипотенуза,
   - \(AC = 20\) — катет, прилежащий к углу \(A\).

2. Найдём катет \(BC\) (противолежащий углу \(A\)) по теореме Пифагора:
   \[
   BC = \sqrt{AB^2 - AC^2} = \sqrt{25^2 - 20^2} = \sqrt{625 - 400} = \sqrt{225} = 15.
   \]

3. Синус острого угла \(A\) — это отношение противолежащего катета к гипотенузе:
   \[
   \sin A = \frac{BC}{AB} = \frac{15}{25} = 0,6.
   \]

---

# Ответ

0,6
