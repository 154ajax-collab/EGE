# Задание

Впишите правильный ответ.

Найдите корень уравнения \(\sqrt{9x - 47} = 4\).

---

# Решение

1. Возведём обе части уравнения в квадрат:
   \[
   (\sqrt{9x - 47})^2 = 4^2
   \]
   \[
   9x - 47 = 16
   \]

2. Решим линейное уравнение:
   \[
   9x = 16 + 47
   \]
   \[
   9x = 63
   \]
   \[
   x = 7
   \]

3. Проверка (подставим в исходное уравнение):
   \[
   \sqrt{9 \cdot 7 - 47} = \sqrt{63 - 47} = \sqrt{16} = 4
   \]
   Корень подходит.

---

# Ответ

7
