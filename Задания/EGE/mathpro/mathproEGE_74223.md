# Задание

Впишите правильный ответ.

В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 5\), \(BC = 4\). Найдите \(\cos A\).

---

# Решение

1. В прямоугольном треугольнике \(ABC\) с прямым углом \(C\):
   - \(AB = 5\) — гипотенуза,
   - \(BC = 4\) — катет, противолежащий углу \(A\).

2. Найдём катет \(AC\) (прилежащий к углу \(A\)) по теореме Пифагора:
   \[
   AC = \sqrt{AB^2 - BC^2} = \sqrt{5^2 - 4^2} = \sqrt{25 - 16} = \sqrt{9} = 3.
   \]

3. Косинус острого угла \(A\) — это отношение прилежащего катета к гипотенузе:
   \[
   \cos A = \frac{AC}{AB} = \frac{3}{5} = 0,6.
   \]

---

# Ответ

0,6
