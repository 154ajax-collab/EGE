# Задание

Впишите правильный ответ.

Найдите корень уравнения \(\log_5 (3 - x) = \log_5 7\).

---

# Решение

1. Так как основания логарифмов равны, приравниваем аргументы:
   \[
   3 - x = 7
   \]

2. Решаем линейное уравнение:
   \[
   -x = 7 - 3
   \]
   \[
   -x = 4
   \]
   \[
   x = -4
   \]

3. Проверяем область определения: \(3 - x > 0 \Rightarrow 3 - (-4) = 7 > 0\) — подходит.

---

# Ответ

-4
