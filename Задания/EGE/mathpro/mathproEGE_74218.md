# Задание

Впишите правильный ответ.

В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 25\), \(BC = 15\). Найдите \(\cos A\).

---

# Решение

1. В прямоугольном треугольнике \(ABC\) с прямым углом \(C\):
   - \(AB = 25\) — гипотенуза,
   - \(BC = 15\) — катет, противолежащий углу \(A\).

2. Найдём катет \(AC\) (прилежащий к углу \(A\)) по теореме Пифагора:
   \[
   AC = \sqrt{AB^2 - BC^2} = \sqrt{25^2 - 15^2} = \sqrt{625 - 225} = \sqrt{400} = 20
   \]

3. Косинус острого угла \(A\) — это отношение прилежащего катета к гипотенузе:
   \[
   \cos A = \frac{AC}{AB} = \frac{20}{25} = 0,8
   \]

---

# Ответ

0,8
