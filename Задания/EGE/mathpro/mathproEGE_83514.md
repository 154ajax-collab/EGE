# Задание

Впишите правильный ответ.

В четырёхугольник \(ABCD\), периметр которого равен 28, вписана окружность, \(AB = 6\). Найдите длину стороны \(CD\).

---

# Решение

1. Если в четырёхугольник можно вписать окружность, то суммы длин противоположных сторон равны:
   \[
   AB + CD = BC + AD.
   \]

2. Периметр четырёхугольника:
   \[
   AB + BC + CD + AD = 28.
   \]

3. Так как \(AB + CD = BC + AD\), то:
   \[
   2(AB + CD) = 28 \quad \Rightarrow \quad AB + CD = 14.
   \]

4. Подставляем \(AB = 6\):
   \[
   6 + CD = 14 \quad \Rightarrow \quad CD = 8.
   \]

---

# Ответ

8
