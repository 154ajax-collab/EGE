# Задание

Впишите правильный ответ.

Найдите значение выражения \(\log_3 162 - \log_3 2\).

---

# Решение

1. Используем свойство логарифмов:  
   \[
   \log_a b - \log_a c = \log_a \frac{b}{c}.
   \]

2. Применяем:  
   \[
   \log_3 162 - \log_3 2 = \log_3 \frac{162}{2} = \log_3 81.
   \]

3. Так как \(81 = 3^4\), получаем:  
   \[
   \log_3 81 = 4.
   \]

---

# Ответ

4
