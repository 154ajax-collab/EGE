# Задание

Впишите правильный ответ.

Цилиндр и конус имеют общие основание и высоту. Высота цилиндра равна радиусу основания. Площадь боковой поверхности цилиндра равна \(4\sqrt{2}\). Найдите площадь боковой поверхности конуса.

---

# Решение

1. Обозначим:
   - \(R\) — радиус основания (общий для цилиндра и конуса),
   - \(H\) — высота (общая),
   - по условию \(H = R\).

2. Площадь боковой поверхности цилиндра:
   \[
   S_{\text{цил}} = 2\pi R H = 2\pi R \cdot R = 2\pi R^2.
   \]
   По условию \(S_{\text{цил}} = 4\sqrt{2}\), значит:
   \[
   2\pi R^2 = 4\sqrt{2} \quad \Rightarrow \quad \pi R^2 = 2\sqrt{2}.
   \]

3. Для конуса образующая \(l\):
   \[
   l = \sqrt{R^2 + H^2} = \sqrt{R^2 + R^2} = \sqrt{2R^2} = R\sqrt{2}.
   \]

4. Площадь боковой поверхности конуса:
   \[
   S_{\text{кон}} = \pi R l = \pi R \cdot R\sqrt{2} = \pi R^2 \sqrt{2}.
   \]

5. Подставляем \(\pi R^2 = 2\sqrt{2}\):
   \[
   S_{\text{кон}} = 2\sqrt{2} \cdot \sqrt{2} = 2 \cdot 2 = 4.
   \]

---

# Ответ

4
