# Задание

Впишите правильный ответ.

В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 25\), \(AC = 15\). Найдите \(\sin A\).

---

# Решение

1. В прямоугольном треугольнике \(ABC\) с прямым углом \(C\):
   - \(AB = 25\) — гипотенуза,
   - \(AC = 15\) — катет, прилежащий к углу \(A\).

2. Найдём катет \(BC\) (противолежащий углу \(A\)) по теореме Пифагора:
   \[
   BC = \sqrt{AB^2 - AC^2} = \sqrt{25^2 - 15^2} = \sqrt{625 - 225} = \sqrt{400} = 20
   \]

3. Синус острого угла \(A\) — это отношение противолежащего катета к гипотенузе:
   \[
   \sin A = \frac{BC}{AB} = \frac{20}{25} = 0,8
   \]

---

# Ответ

0,8
