# Задание

Дайте развернутый ответ.

Решите неравенство 
\[
\frac{\log_3 (9x) \cdot \log_4 (64x)}{5x^2 - |x|} \le 0.
\]

---

# Решение

## 1. Область определения

Логарифмы определены при \(x > 0\).  
Знаменатель не должен равняться нулю:  
\(5x^2 - |x| \neq 0\).

При \(x > 0\), \(|x| = x\), значит:
\[
5x^2 - x = x(5x - 1) \neq 0 \Rightarrow x \neq 0,\; x \neq \frac{1}{5}.
\]

Так как \(x > 0\), область определения:
\[
x > 0,\quad x \neq \frac{1}{5}.
\]

---

## 2. Упростим логарифмы

\[
\log_3 (9x) = \log_3 9 + \log_3 x = 2 + \log_3 x.
\]

\[
\log_4 (64x) = \log_4 64 + \log_4 x = 3 + \log_4 x.
\]

---

## 3. Замена переменной

Пусть \(t = \log_3 x\). Тогда \(x = 3^t\).  
Так как \(x > 0\), \(t \in \mathbb{R}\).

Выразим \(\log_4 x\) через \(t\):
\[
\log_4 x = \frac{\ln x}{\ln 4} = \frac{\ln 3}{\ln 4} \cdot t = \frac{\log_3 4}{\log_3 3}? 
\]
Проще: \(\log_4 x = \log_4 3^t = t \cdot \log_4 3\).

Но можно оставить как \(\log_4 x\).

---

## 4. Знак числителя

Числитель:  
\[
(2 + \log_3 x)(3 + \log_4 x).
\]

Найдём нули:
1. \(2 + \log_3 x = 0 \Rightarrow \log_3 x = -2 \Rightarrow x = 3^{-2} = \frac{1}{9}.\)

2. \(3 + \log_4 x = 0 \Rightarrow \log_4 x = -3 \Rightarrow x = 4^{-3} = \frac{1}{64}.\)

---

## 5. Знак знаменателя

При \(x > 0\):  
\(5x^2 - |x| = 5x^2 - x = x(5x - 1)\).

Нули знаменателя: \(x = 0\) (не входит в ОДЗ), \(x = \frac{1}{5}\).

Знак знаменателя:
- На \( (0; \frac{1}{5}) \): \(x > 0,\; 5x - 1 < 0\) → знаменатель отрицателен.
- На \( (\frac{1}{5}; \infty) \): \(x > 0,\; 5x - 1 > 0\) → знаменатель положителен.

---

## 6. Знаки числителя

Точки: \(x = \frac{1}{64} \approx 0,0156\), \(x = \frac{1}{9} \approx 0,111\).

Расположение на оси:  
\(0 < \frac{1}{64} < \frac{1}{9} < \frac{1}{5} < \infty\).

Рассмотрим интервалы:

1. \(0 < x < \frac{1}{64}\):  
   \(\log_3 x < -3\)? Нет, \(\log_3 x < -3\)? Проверим: при \(x < 1/64\), \(\log_3 x < -3\) (так как \(3^{-3} = 1/27 > 1/64\)).  
   Точнее: \(x < 1/64 \Rightarrow \log_3 x < \log_3 (1/64) \approx -3,79\), значит \(2 + \log_3 x < 0\).  
   \(x < 1/64 \Rightarrow \log_4 x < -3\) (так как \(4^{-3} = 1/64\)), значит \(3 + \log_4 x < 0\).  
   Произведение двух отрицательных → числитель **положителен**.

2. \(\frac{1}{64} < x < \frac{1}{9}\):  
   \(\log_3 x\) между \(-3,79\) и \(-2\) → \(2 + \log_3 x < 0\).  
   \(\log_4 x\) между \(-3\) и \(-2,09\) → \(3 + \log_4 x > 0\).  
   Произведение \((-)(+) = -\) → числитель **отрицателен**.

3. \(\frac{1}{9} < x < \frac{1}{5}\):  
   \(2 + \log_3 x > 0\) (так как \(\log_3 x > -2\)),  
   \(3 + \log_4 x > 0\) (так как \(\log_4 x > -3\)).  
   Произведение двух положительных → числитель **положителен**.

4. \(x > \frac{1}{5}\):  
   числитель положителен (оба множителя положительны).

---

## 7. Общий знак дроби

Дробь ≤ 0, когда числитель и знаменатель разных знаков (или числитель равен 0).

- На \((0; \frac{1}{64})\): числитель \(+\), знаменатель \(−\) → дробь \(−\) → **подходит**.
- На \((\frac{1}{64}; \frac{1}{9})\): числитель \(−\), знаменатель \(−\) → дробь \(+\) → **не подходит**.
- На \((\frac{1}{9}; \frac{1}{5})\): числитель \(+\), знаменатель \(−\) → дробь \(−\) → **подходит**.
- На \((\frac{1}{5}; \infty)\): числитель \(+\), знаменатель \(+\) → дробь \(+\) → **не подходит**.

---

## 8. Точки, где числитель равен нулю

- \(x = \frac{1}{64}\) — числитель равен 0 → дробь равна 0 → **подходит**.
- \(x = \frac{1}{9}\) — числитель равен 0 → дробь равна 0 → **подходит**.

---

## 9. Ответ

\[
(0; \frac{1}{64}] \cup [\frac{1}{9}; \frac{1}{5}).
\]

---

# Ответ

\((0; \frac{1}{64}] \cup [\frac{1}{9}; \frac{1}{5})\)
