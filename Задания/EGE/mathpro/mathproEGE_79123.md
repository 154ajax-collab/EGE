# Задание

Впишите правильный ответ.

В треугольнике \(ABC\) стороны \(AC\) и \(BC\) равны, угол \(C\) равен \(162^\circ\), угол \(CBD\) — внешний. Найдите величину угла \(CBD\). Ответ дайте в градусах.

---

# Решение

1. Треугольник \(ABC\) — равнобедренный, так как \(AC = BC\). Значит, углы при основании \(AB\) равны:
   \[
   \angle A = \angle B.
   \]

2. Сумма углов в треугольнике \(ABC\):
   \[
   \angle A + \angle B + \angle C = 180^\circ.
   \]
   Подставляем \(\angle C = 162^\circ\):
   \[
   2\angle B + 162^\circ = 180^\circ,
   \]
   \[
   2\angle B = 18^\circ,
   \]
   \[
   \angle B = 9^\circ.
   \]

3. Угол \(CBD\) — внешний при вершине \(B\), он смежный с углом \(ABC\):
   \[
   \angle CBD = 180^\circ - \angle ABC = 180^\circ - 9^\circ = 171^\circ.
   \]

---

# Ответ

171
