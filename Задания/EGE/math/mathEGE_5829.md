# Задание

Впишите правильный ответ.

В трапеции \(ABCD\) известно, что \(AB = CD\), \(\angle BDA = 48^\circ\) и \(\angle BDC = 22^\circ\). Найдите величину угла \(ABD\). Ответ дайте в градусах.

---

# Решение

1. Трапеция \(ABCD\) с \(AB = CD\) — равнобедренная (углы при основаниях равны).

2. \(\angle BDA = 48^\circ\) и \(\angle BDC = 22^\circ\) — это углы при диагонали \(BD\).  
   \(\angle ADC = \angle BDA + \angle BDC = 48^\circ + 22^\circ = 70^\circ\).

3. В равнобедренной трапеции углы при основании \(AD\) равны:  
   \(\angle BAD = \angle ADC = 70^\circ\).

4. В треугольнике \(ABD\):
   - \(\angle BAD = 70^\circ\),
   - \(\angle BDA = 48^\circ\),
   - \(\angle ABD\) находим по сумме углов треугольника:
     \[
     \angle ABD = 180^\circ - 70^\circ - 48^\circ = 62^\circ
     \]

---

# Ответ

62
