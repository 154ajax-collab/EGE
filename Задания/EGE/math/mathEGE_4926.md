# Задание

Впишите правильный ответ.

Диагональ прямоугольного экрана телевизора равна 65 см, а высота экрана 33 см. Найдите ширину экрана. Ответ дайте в сантиметрах.

---

# Решение

1. Экран телевизора имеет форму прямоугольника.  
   Диагональ \(d = 65\) см, высота \(h = 33\) см.

2. По теореме Пифагора для прямоугольного треугольника, образованного диагональю, высотой и шириной:
   \[
   d^2 = h^2 + w^2
   \]
   где \(w\) — ширина экрана.

3. Выражаем ширину:
   \[
   w = \sqrt{d^2 - h^2} = \sqrt{65^2 - 33^2} = \sqrt{4225 - 1089} = \sqrt{3136} = 56
   \]

---

# Ответ

56
