# Задание

Установите соответствие и впишите ответ.

Установите соответствие между функциями и характеристиками этих функций.

| ФУНКЦИИ | ХАРАКТЕРИСТИКИ |
|---------|----------------|
| А) \(y = 3x - 2\) | 1) функция возрастающая |
| Б) \(y = x^2 - 3x + 1\) | 2) функция убывающая |
| В) \(y = 5x - x^2\) | 3) функция имеет точку минимума |
| Г) \(y = 4 - 2x\) | 4) функция имеет точку максимума |

В таблице под каждой буквой укажите соответствующий номер.

| А | Б | В | Г |
|---|---|---|---|
|   |   |   |   |

---

# Решение

1. **А) \(y = 3x - 2\)** — линейная функция с угловым коэффициентом \(k = 3 > 0\), значит, функция **возрастающая**.  
   Соответствует характеристике **1**.

2. **Б) \(y = x^2 - 3x + 1\)** — квадратичная функция, коэффициент при \(x^2\) положительный (\(a = 1 > 0\)), ветви параболы направлены вверх, значит, функция имеет **точку минимума**.  
   Соответствует характеристике **3**.

3. **В) \(y = 5x - x^2\)** — квадратичная функция, коэффициент при \(x^2\) отрицательный (\(a = -1 < 0\)), ветви параболы направлены вниз, значит, функция имеет **точку максимума**.  
   Соответствует характеристике **4**.

4. **Г) \(y = 4 - 2x\)** — линейная функция с угловым коэффициентом \(k = -2 < 0\), значит, функция **убывающая**.  
   Соответствует характеристике **2**.
