# Задание

Впишите правильный ответ.

В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 25\), \(AC = 20\). Найдите \(\cos B\).

---

# Решение

1. В прямоугольном треугольнике \(ABC\) с прямым углом \(C\):
   - \(AB = 25\) — гипотенуза,
   - \(AC = 20\) — катет, противолежащий углу \(B\).

2. Найдём катет \(BC\) (прилежащий к углу \(B\)) по теореме Пифагора:
   \[
   BC = \sqrt{AB^2 - AC^2} = \sqrt{25^2 - 20^2} = \sqrt{625 - 400} = \sqrt{225} = 15
   \]

3. Косинус острого угла \(B\) — это отношение прилежащего катета к гипотенузе:
   \[
   \cos B = \frac{BC}{AB} = \frac{15}{25} = 0,6
   \]

---

# Ответ

0,6
