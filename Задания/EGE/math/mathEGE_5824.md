# Задание

Перила лестницы дачного дома для надёжности укреплены посередине вертикальным столбом. Найдите высоту \(l\) этого столба, если наименьшая высота \(h_1\) перил равна 2,0 м, а наибольшая высота \(h_2\) равна 4,0 м. Ответ дайте в метрах.

---

# Решение

1. Вертикальный столб расположен **посередине**, значит, он является средней линией трапеции, где основания — это \(h_1\) и \(h_2\).

2. Средняя линия трапеции находится по формуле:
   \[
   l = \frac{h_1 + h_2}{2}
   \]

3. Подставляем значения:
   \[
   l = \frac{2,0 + 4,0}{2} = \frac{6}{2} = 3
   \]

---

# Ответ

3
