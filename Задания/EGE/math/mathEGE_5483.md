# Задание

Впишите правильный ответ.

Закон Гука можно записать в виде \(F = kx\), где \(F\) — сила (в ньютонах), с которой растягивают пружину, \(x\) — абсолютное удлинение пружины (в метрах), \(k\) — коэффициент упругости (в Н/м). Пользуясь этой формулой, найдите \(x\) (в метрах), если \(F = 48\) Н и \(k = 4\) Н/м.

---

# Решение

1. По формуле закона Гука:
   \[
   F = kx
   \]

2. Выражаем \(x\):
   \[
   x = \frac{F}{k}
   \]

3. Подставляем значения:
   \[
   x = \frac{48}{4} = 12
   \]

---

# Ответ

12
