# Задание

Установите соответствие и впишите ответ.

Число \(m\) равно \(\log_2 5\).

Каждому из четырёх чисел в левом столбце соответствует отрезок, которому оно принадлежит. Установите соответствие между числами и отрезками из правого столбца.

| ЧИСЛА | ОТРЕЗКИ |
|-------|---------|
| А) \(m\) | 1) \([2; 3]\) |
| Б) \(m + 1\) | 2) \([3; 4]\) |
| В) \(m + 2\) | 3) \([4; 5]\) |
| Г) \(m + 3\) | 4) \([5; 6]\) |

Запишите в приведённой в ответе таблице под каждой буквой соответствующий отрезку номер.

| А | Б | В | Г |
|---|---|---|---|
|   |   |   |   |

---

# Решение

1. \(m = \log_2 5 \approx 2,32\).

2. **А) \(m\)**: \(2,32 \in [2; 3] \Rightarrow \text{1}\)

3. **Б) \(m + 1\)**: \(3,32 \in [3; 4] \Rightarrow \text{2}\)

4. **В) \(m + 2\)**: \(4,32 \in [4; 5] \Rightarrow \text{3}\)

5. **Г) \(m + 3\)**: \(5,32 \in [5; 6] \Rightarrow \text{4}\)
