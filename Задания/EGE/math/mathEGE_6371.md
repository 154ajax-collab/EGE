# Задание

В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 25\), \(AC = 15\). Найдите \(\cos B\).

---

# Решение

1. В прямоугольном треугольнике \(ABC\) с прямым углом \(C\):
   - \(AB = 25\) — гипотенуза,
   - \(AC = 15\) — катет, противолежащий углу \(B\).

2. Найдём катет \(BC\) (прилежащий к углу \(B\)) по теореме Пифагора:
   \[
   BC = \sqrt{AB^2 - AC^2} = \sqrt{25^2 - 15^2} = \sqrt{625 - 225} = \sqrt{400} = 20
   \]

3. Косинус острого угла \(B\) — это отношение прилежащего катета к гипотенузе:
   \[
   \cos B = \frac{BC}{AB} = \frac{20}{25} = 0,8
   \]

---

# Ответ

0,8
