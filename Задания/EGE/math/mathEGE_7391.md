# Задание

Перила лестницы дачного дома для надёжности укреплены посередине вертикальным столбом. Найдите высоту \(l\) этого столба, если наименьшая высота \(h_1\) перил равна 1,8 м, а наибольшая высота \(h_2\) равна 3,2 м. Ответ дайте в метрах.

---

# Решение

1. Вертикальный столб расположен **посередине**, значит, он является средней линией трапеции, где основания — это \(h_1\) и \(h_2\).

2. Средняя линия трапеции находится по формуле:
   \[
   l = \frac{h_1 + h_2}{2}
   \]

3. Подставляем значения:
   \[
   l = \frac{1,8 + 3,2}{2} = \frac{5}{2} = 2,5
   \]

---

# Ответ

2,5
