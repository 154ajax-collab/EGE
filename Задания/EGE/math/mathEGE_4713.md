# Задание

Впишите правильный ответ.

Найдите значение выражения \(4,2 \cdot 6,5 + 0,7\).

---

# Решение

1. Выполняем умножение:
   \[
   4,2 \cdot 6,5 = 27,3
   \]

2. Прибавляем \(0,7\):
   \[
   27,3 + 0,7 = 28
   \]

---

# Ответ

28
