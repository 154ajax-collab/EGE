# Задание

Впишите правильный ответ.

В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 10\), \(AC = 6\). Найдите \(\sin A\).

---

# Решение

1. В прямоугольном треугольнике \(ABC\) с прямым углом \(C\):
   - \(AB = 10\) — гипотенуза,
   - \(AC = 6\) — катет, прилежащий к углу \(A\).

2. Синус острого угла \(A\) — это отношение противолежащего катета к гипотенузе.  
   Противолежащий катет к углу \(A\) — это \(BC\).

3. Найдём катет \(BC\) по теореме Пифагора:
   \[
   BC = \sqrt{AB^2 - AC^2} = \sqrt{10^2 - 6^2} = \sqrt{100 - 36} = \sqrt{64} = 8
   \]

4. Теперь найдём \(\sin A\):
   \[
   \sin A = \frac{BC}{AB} = \frac{8}{10} = 0,8
   \]

---

# Ответ

0,8
