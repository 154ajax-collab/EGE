# Задание

Впишите правильный ответ.

На шести карточках написаны цифры 3; 3; 4; 5; 7; 8 (по одной цифре на каждой карточке). В выражении

\[
\Box\Box + \Box\Box = \Box\Box
\]

квадратики заменили карточками из данного набора (каждую цифру можно использовать только один раз). Оказалось, что полученная сумма делится на 5, но не делится на 10. В ответе запишите какую-нибудь одну такую сумму.

---

# Решение

1. Нам нужно составить выражение вида:  
   \( \overline{ab} + \overline{cd} = \overline{ef} \), где \(a, b, c, d, e, f\) — различные цифры из набора {3, 3, 4, 5, 7, 8}, причём цифра 3 встречается дважды, остальные — по одному разу.

2. Условия:
   - Сумма должна делиться на 5, но не делиться на 10.  
     Это значит, что сумма оканчивается на **5** (делится на 5, но не на 10).

3. Подберём пример:
   - Возьмём \(34 + 57 = 91\) — не подходит (не делится на 5).
   - Возьмём \(37 + 48 = 85\) — подходит: 85 делится на 5, но не делится на 10.
   - Проверим цифры: 3, 7, 4, 8, 5 — все есть в наборе, и цифра 3 используется один раз (вторую тройку можно не использовать).

4. Сумма равна **85**.

---

# Ответ

85
