# Задание

Пешеход и велосипедист одновременно отправились из посёлков, расстояние между которыми 42 км, навстречу друг другу. Они встретились через 3 часа. Скорость велосипедиста на 7 км/ч больше скорости пешехода. Найдите скорость пешехода. Ответ дайте в км/ч.

---

# Решение

Пусть скорость пешехода равна \(x\) км/ч.  
Тогда скорость велосипедиста равна \(x + 7\) км/ч.

Скорость сближения:
\[
x + (x + 7) = 2x + 7
\]

За 3 часа они вместе преодолели 42 км:
\[
3 \cdot (2x + 7) = 42
\]
\[
2x + 7 = 14
\]
\[
2x = 7
\]
\[
x = 3,5
\]

**Ответ:** 3,5

--- 

# Ответ

3,5
