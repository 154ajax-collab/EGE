# Задание

В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(CH\) — высота, \(BC = 20\), \(\sin A = 0,4\). Найдите длину отрезка \(BH\).

---

# Решение

1. В прямоугольном треугольнике \(ABC\) с прямым углом \(C\):
   - \(BC\) — катет, противолежащий углу \(A\),
   - \(\sin A = \frac{BC}{AB}\).

2. Найдём гипотенузу \(AB\):
   \[
   AB = \frac{BC}{\sin A} = \frac{20}{0,4} = 50
   \]

3. В прямоугольном треугольнике \(ABC\) высота \(CH\), проведённая к гипотенузе, делит её на отрезки:
   \[
   BH = \frac{BC^2}{AB}
   \]
   (проекция катета \(BC\) на гипотенузу).

4. Подставляем значения:
   \[
   BH = \frac{20^2}{50} = \frac{400}{50} = 8
   \]

---

# Ответ

8
