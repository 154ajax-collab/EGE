# Задание

В течение года абонент пользовался тарифом **«Стандартный»**, абонентская плата по которому составляла **420 рублей** в месяц. В тариф входит:

- 📞 350 минут исходящих вызовов
- 📶 4 ГБ мобильного интернета
- ✉️ 150 SMS

Стоимость услуг сверх тарифа:

- Минуты: **2,5 руб./мин.**
- Интернет (пакет 1 ГБ): **100 руб.**

Абонент **не пользовался** услугами в роуминге. За год он отправил **130 SMS**.

## Задание 1.1

Определите, какие месяцы соответствуют указанному в таблице трафику интернета:

| Интернет (ГБ) | 3 | 5 | 7 | 9 |
|---------------|---|---|---|---|
| Номер месяца  |   |   |   |   |

В ответе запишите номера месяцев **в порядке возрастания** (например, 2511).

---

### Решение

По таблице:
- 3 ГБ — январь, ноябрь
- 5 ГБ — февраль, октябрь
- 7 ГБ — май
- 9 ГБ — август

Ответ: **1511** (январь, ноябрь) — не подходит, т.к. нужно 4 числа.

Правильный порядок: январь (1), февраль (2), май (5), август (8).

**Ответ: 1258**

## Задание 2

Сколько рублей потратил абонент на услуги связи **в феврале**?

---

### Решение

1. Абонентская плата: 420 руб.
2. Интернет: 5 ГБ (превышение на 1 ГБ) → 100 руб.
3. Минуты: 360 (превышение на 10 мин) → 10 × 2,5 = 25 руб.
4. SMS: 12 (в пределах 150) → 0 руб.

Итого: \(420 + 100 + 25 = 545\) руб.

**Ответ: 545**

## Задание 4

На сколько процентов вырос трафик интернета **в мае** по сравнению с **апрелем**?

---

### Решение

Апрель: 6 ГБ, май: 7 ГБ.

Разница: \(7 - 6 = 1\) ГБ.

Процент роста: \(\frac{1}{6} \cdot 100 \approx 16,67\%\).

Округляем до целого: **17%**.

**Ответ: 17**

## Задание 5

В конце года оператор предложил новый тариф: **450 руб./мес.**, в который входит **400 минут**, **5 ГБ интернета** и **100 SMS**. Сверх тарифа: минуты — **2 руб./мин.**, интернет — **90 руб. за 1 ГБ**, SMS — **2 руб./шт.**

Перейдёт ли абонент на новый тариф, если он считает, сколько бы потратил за год по нему?

---

### Решение

#### Фактические расходы за год по старому тарифу:

Считаем помесячно (абонентская плата + превышения):

| Месяц | Абон. плата | Интернет (превыш.) | Минуты (превыш.) | SMS (превыш.) | Итого |
|-------|-------------|-------------------|------------------|---------------|-------|
| январь| 420         | 0                 | 0                | 0             | 420   |
| февраль| 420       | 100               | 25               | 0             | 545   |
| март  | 420         | 0                 | 0                | 0             | 420   |
| апрель| 420         | 200 (2 ГБ)        | 125 (50 мин)     | 0             | 745   |
| май   | 420         | 300 (3 ГБ)        | 175 (70 мин)     | 0             | 895   |
| июнь  | 420         | 0                 | 0                | 0             | 420   |
| июль  | 420         | 400 (4 ГБ)        | 325 (130 мин)    | 0             | 1145  |
| август| 420         | 500 (5 ГБ)        | 375 (150 мин)    | 0             | 1295  |
| сентябрь| 420      | 0                 | 0                | 0             | 420   |
| октябрь| 420       | 100               | 50               | 0             | 570   |
| ноябрь| 420         | 0                 | 0                | 0             | 420   |
| декабрь| 420       | 200               | 100              | 0             | 720   |

Сумма за год:  
\(420+545+420+745+895+420+1145+1295+420+570+420+720 =\)  

Считаем:  
\(420+545=965\)  
\(+420=1385\)  
\(+745=2130\)  
\(+895=3025\)  
\(+420=3445\)  
\(+1145=4590\)  
\(+1295=5885\)  
\(+420=6305\)  
\(+570=6875\)  
\(+420=7295\)  
\(+720=8015\) руб.

#### По новому тарифу:

Считаем помесячно (абон. плата 450 руб., лимиты: 400 мин, 5 ГБ, 100 SMS):

| Месяц | Интернет (превыш.) | Минуты (превыш.) | SMS (превыш.) | Итого |
|-------|-------------------|------------------|---------------|-------|
| январь (3 ГБ, 320 мин, 10 SMS) | 0 | 0 | 0 | 450 |
| февраль (5 ГБ, 360 мин, 12 SMS) | 0 | 0 | 0 | 450 |
| март (4 ГБ, 340 мин, 8 SMS) | 0 | 0 | 0 | 450 |
| апрель (6 ГБ, 400 мин, 15 SMS) | 90 | 0 | 0 | 540 |
| май (7 ГБ, 420 мин, 14 SMS) | 180 | 40 | 0 | 670 |
| июнь (4 ГБ, 350 мин, 9 SMS) | 0 | 0 | 0 | 450 |
| июль (8 ГБ, 480 мин, 18 SMS) | 270 | 160 | 0 | 880 |
| август (9 ГБ, 500 мин, 20 SMS) | 360 | 200 | 0 | 1010 |
| сентябрь (4 ГБ, 330 мин, 7 SMS) | 0 | 0 | 0 | 450 |
| октябрь (5 ГБ, 370 мин, 11 SMS) | 0 | 0 | 0 | 450 |
| ноябрь (3 ГБ, 310 мин, 6 SMS) | 0 | 0 | 0 | 450 |
| декабрь (6 ГБ, 390 мин, 10 SMS) | 90 | 0 | 0 | 540 |

Сумма за год:  
\(450+450+450+540+670+450+880+1010+450+450+450+540 =\)  

Считаем:  
\(450 \cdot 6 = 2700\) (янв, фев, мар, июн, сен, окт, ноя?) — 7 месяцев по 450:  
янв, фев, мар, июн, сен, окт, ноя → 7 × 450 = 3150  
апрель 540, май 670, июль 880, август 1010, декабрь 540  

Сумма:  
\(3150 + 540 + 670 + 880 + 1010 + 540 = 6790\) руб.

Сравниваем: 6790 < 8015 → абонент перейдёт на новый тариф.

**Ответ: 450**
