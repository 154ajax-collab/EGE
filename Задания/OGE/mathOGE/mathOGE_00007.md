# Задание

Впишите правильный ответ.

Один из углов прямоугольной трапеции равен 45°. Найдите больший угол этой трапеции. Ответ дайте в градусах.

---

# Решение

1. В прямоугольной трапеции два угла прямые (по 90°).

2. Сумма углов четырёхугольника равна 360°.

3. Пусть один из острых углов равен 45°. Тогда второй острый угол равен:
   \[
   360° - 90° - 90° - 45° = 135°
   \]

4. Больший угол трапеции — **135°**.

---

# Ответ

135
