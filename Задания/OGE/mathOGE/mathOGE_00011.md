# Задание

Впишите правильный ответ.

Центр окружности, описанной около треугольника \(ABC\), лежит на стороне \(AB\). Найдите угол \(ABC\), если угол \(BAC\) равен 40°. Ответ дайте в градусах.

---

# Решение

1. Если центр описанной окружности лежит на стороне \(AB\), значит \(AB\) — диаметр этой окружности.

2. Вписанный угол, опирающийся на диаметр, равен 90°:
   \[
   \angle ACB = 90^\circ
   \]

3. Сумма углов треугольника равна 180°:
   \[
   \angle ABC = 180^\circ - 90^\circ - 40^\circ = 50^\circ
   \]

---

# Ответ

50
