# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для данных пунктуационных правил: к каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Уточняющее обстоятельство обособляется. | 1) В глубокой тени, падавшей от старых раскидистых дубов, поблёскивали, словно маленькие зеркальца, капли росы на траве. |
| Б) Если вторая часть бессоюзного сложного предложения дополняет первую, то между частями предложения ставится двоеточие. | 2) У крыльца, у самой калитки, толпилось много народу: местные жители пришли посмотреть на приезжих артистов. |
| В) Между частями сложноподчинённого предложения ставится запятая. | 3) На одной из скамеек парка Николай увидел знакомый силуэт, он присмотрелся: это была его давняя подруга. |
| | 4) Всё вокруг ликовало и пело: и поле, и лес, и звонкие ручьи, и птицы в вышине. |
| | 5) В том месте, откуда доносились голоса, загорелся и погас один огонёк, а затем другой. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Уточняющее обстоятельство обособляется** — предложение 2:  
   «У крыльца, **у самой калитки**, толпилось много народу...»  
   Обстоятельство «у самой калитки» уточняет место действия.  
   **А → 2**

2. **Б) Двоеточие в бессоюзном предложении (дополнение)** — предложение 3:  
   «На одной из скамеек парка Николай увидел знакомый силуэт, он присмотрелся: это была его давняя подруга.»  
   Вторая часть дополняет первую (что именно увидел).  
   **Б → 3**

3. **В) Запятая между частями сложноподчинённого предложения** — предложение 5:  
   «В том месте, **откуда доносились голоса**, загорелся и погас один огонёк, а затем другой.»  
   Придаточное определительное выделяется запятыми.  
   **В → 5**
