# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для данных пунктуационных правил: к каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Обращение отделяется запятой. | 1) Дети радовались и хорошей погоде, и встречам с одноклассниками, и короткому дождю, оставившему лужи на асфальте. |
| Б) Между однородными членами предложения, связанными повторяющимся союзом, ставится запятая. | 2) Высоко пари́т, распластав крылья, орёл – гроза пернатого царства. |
| В) Между подлежащим и сказуемым, выраженными именами существительными в именительном падеже, при нулевой связке ставится тире. | 3) Солнце только что село, и алый тонкий свет лежал на зелёных лозах, на сухой земле и на белой стене небольшого домика, стоявшего на самом верху горы. |
| | 4) «Поди прочь, безумный мальчишка!» – нетерпеливо прервал Азамата Ка́збич. |
| | 5) Папе стихи понравились, он поцеловал Виту в щёчку и сказал, что его дочь – настоящая поэтесса вроде Агнии Барто. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Обращение отделяется запятой** — предложение 4:  
   «Поди прочь, **безумный мальчишка!**» — обращение «безумный мальчишка» выделяется запятыми.  
   **А → 4**

2. **Б) Однородные члены с повторяющимся союзом** — предложение 1:  
   «Дети радовались **и** хорошей погоде, **и** встречам с одноклассниками, **и** короткому дождю...» — повторяющийся союз **и** соединяет однородные дополнения, между ними ставятся запятые.  
   **Б → 1**

3. **В) Тире между подлежащим и сказуемым** — предложение 5:  
   «...его дочь **–** настоящая поэтесса...» — подлежащее и сказуемое выражены существительными в именительном падеже (дочь — поэтесса), ставится тире.  
   **В → 5**
