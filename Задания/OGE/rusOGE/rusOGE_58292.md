# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для данных пунктуационных правил: к каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Определение, выраженное причастным оборотом, стоящим после определяемого слова, обособляется. | 1) Вскоре после захода солнца полевой стан опустел: тракторы ушли на стоянки, а отработавшая смена ужинала в палатке. |
| Б) Между однородными членами предложения перед второй частью двойного союза ставится запятая. | 2) Коллекция лекарственных трав, которую собрал учёный, известна не только отечественным, но и зарубежным специалистам. |
| В) Если обобщающее слово стоит перед однородными членами, то после него ставится двоеточие. | 3) Стёпка наскоро умылся, съел холодный огурец с куском хлеба, выскочил на улицу, накинув на худенькие плечи курточку. |
| | 4) Теперь уж ничего не было видно: ни гор, ни неба, ни земли. |
| | 5) Прерванный на минуту разговор возобновился, и Николай мог свободно разглядеть общество, сидящее за столом. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Причастный оборот после определяемого слова** — предложение 5:  
   «...общество, **сидящее за столом**» — причастный оборот стоит после определяемого слова «общество» и выделяется запятой.  
   **А → 5**

2. **Б) Двойной союз (не только ... но и)** — предложение 2:  
   «...известна **не только** отечественным, **но и** зарубежным специалистам.»  
   Запятая ставится перед второй частью двойного союза.  
   **Б → 2**

3. **В) Обобщающее слово перед однородными членами** — предложение 4:  
   «Теперь уж ничего не было видно: **ни гор, ни неба, ни земли**» — обобщающее слово «ничего» стоит перед однородными членами, после него ставится двоеточие.  
   **В → 4**
