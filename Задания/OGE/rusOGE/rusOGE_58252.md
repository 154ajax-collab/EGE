# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для данных пунктуационных правил: к каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Если обобщающее слово стоит перед однородными членами, то после него ставится двоеточие. | 1) Луна, яркая и точно мокрая, мелькала по голым верхушкам деревьев, и голые сучья сливались с её влажным блеском, исчезали в нём. |
| Б) Уточняющее обстоятельство обособляется. | 2) Погода стояла неблагоприятная: по временам шёл мелкий осенний дождь, постоянно дул ветер. |
| В) Определение, выраженное причастным оборотом, стоящим после определяемого слова, обособляется. | 3) Приметы связаны со всем: с цветом неба, росой и туманами, криком птиц и яркостью звёздного неба. |
| | 4) Высокое, почти безоблачное летнее небо, наполненное солнечным блеском, было восхитительно. |
| | 5) В детстве мы с братом любили проводить время в заброшенном уголке сада, между сараем и забором, где хранилось множество вышедших из употребления вещей. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Двоеточие после обобщающего слова перед однородными членами** — предложение 3:  
   «Приметы связаны со всем: с цветом неба, росой и туманами, криком птиц и яркостью звёздного неба.»  
   Здесь обобщающее слово **всем** стоит перед однородными членами, после него ставится двоеточие.  
   **А → 3**

2. **Б) Уточняющее обстоятельство обособляется** — предложение 5:  
   «...в заброшенном уголке сада, между сараем и забором, где хранилось множество вышедших из употребления вещей.»  
   Обстоятельство **между сараем и забором** уточняет место (уголок сада) и выделяется запятыми.  
   **Б → 5**

3. **В) Причастный оборот после определяемого слова** — предложение 4:  
   «Высокое, почти безоблачное летнее небо, наполненное солнечным блеском, было восхитительно.»  
   Причастный оборот **наполненное солнечным блеском** стоит после определяемого слова **небо** и выделяется запятыми.  
   **В → 4**
