# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для данных пунктуационных правил: к каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Придаточная часть сложноподчинённого предложения выделяется запятыми. | 1) Вокзал пуст и гулок, ещё не работает в нём ни буфет, ни газетный киоск. |
| Б) Если обобщающее слово стоит перед однородными членами, то после него ставится двоеточие. | 2) Мягкий ветер, дувший с южной стороны, временами усиливался, порывисто бежал по засеянному полю, и колосья сухо и тревожно шелестели. |
| В) Между однородными членами предложения, связанными повторяющимся союзом, ставится запятая. | 3) Взору Алексея предстали явные приметы заброшенности: боковое окно из кухни чернело сплошь разбитыми стёклами, калитки не было, некогда уютный дворик густо зарастал сорной травой. |
| | 4) На бугре, куда вела оловянная от дождевой воды дорога, среди пней и молодой осиновой поросли, горько и свежо пахнущей, одиноко стояла изба. |
| | 5) Вечерело, и тучи заходили теперь с трёх сторон: слева, справа и с запада. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Придаточная часть выделяется запятыми** — предложение 4:  
   «На бугре, **куда вела оловянная от дождевой воды дорога**, среди пней и молодой осиновой поросли...»  
   Придаточное определительное «куда вела дорога» выделяется запятыми.  
   **А → 4**

2. **Б) Двоеточие после обобщающего слова перед однородными членами** — предложение 3:  
   «Взору Алексея предстали явные приметы заброшенности: боковое окно ... калитки не было ... дворик зарастал...»  
   Обобщающее слово **приметы** стоит перед однородными членами, после него ставится двоеточие.  
   **Б → 3**

3. **В) Запятая между однородными членами с повторяющимся союзом** — предложение 1:  
   «...не работает в нём ни буфет, ни газетный киоск.»  
   Повторяющийся союз **ни ... ни** соединяет однородные члены, между ними ставится запятая.  
   **В → 1**
