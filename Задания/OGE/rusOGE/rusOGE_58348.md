# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для данных пунктуационных правил: к каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Если первая и вторая части сложного бессоюзного предложения противопоставлены по смыслу, то между частями предложения ставится тире. | 1) Ромашки, колокольчики, гвоздики сразу бросаются в глаза: и стебли у них высокие, и цветки крупные. |
| Б) Приложение, которое относится к личному местоимению, обособляется. | 2) Нас было трое: старый охотник Савелий, его длинноухий пёс Пыж и я, тогда ещё подросток. |
| В) Если вторая часть бессоюзного сложного предложения дополняет первую, то между частями предложения ставится двоеточие. | 3) Хотел рисовать – кисти выпадали из рук; пробовал читать – глаза не видели строк. |
| | 4) И ещё я увидел: впервые за лето берёзки начали обсыпать золотыми монетками тёмные ёлочки, растущие под ними. |
| | 5) Вдруг мужики с топорами явились – лес зазвенел, застонал, затрещал. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Тире в бессоюзном предложении с противопоставлением** — предложение 3:  
   «Хотел рисовать – кисти выпадали из рук; пробовал читать – глаза не видели строк.»  
   Здесь в каждой части противопоставление (хотел – не мог).  
   **А → 3**

2. **Б) Приложение при личном местоимении** — предложение 2:  
   «...и я, тогда ещё подросток.» — приложение «тогда ещё подросток» относится к личному местоимению «я» и обособляется.  
   **Б → 2**

3. **В) Двоеточие в бессоюзном предложении (дополнение)** — предложение 4:  
   «И ещё я увидел: впервые за лето берёзки начали обсыпать...» — вторая часть дополняет первую (что именно увидел).  
   **В → 4**
