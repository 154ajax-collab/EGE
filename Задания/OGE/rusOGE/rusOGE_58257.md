# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для приведённых пунктуационных правил. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Между однородными членами предложения перед второй частью двойного союза ставится запятая. | 1) Мы плыли на лодке по тёмной, как чернила, реке, петляющей между мрачными скалами. |
| Б) Обстоятельство, выраженное деепричастным оборотом, обособляется. | 2) Н.М. Пржевальский, известный географ и натуралист, путешествовал не только по Дальнему Востоку, но и по Центральной Азии. |
| В) Обстоятельство, выраженное сравнительным оборотом, обособляется. | 3) Звёзды дрожали в тёмно-синей глубине неба, как дрожат капли росы утром на траве, окутанной туманом. |
| | 4) Оставшись один, Алексей ходил по комнате, браня себя вполголоса за невнимательное отношение к сестре. |
| | 5) Кусака долго металась по следам уехавших людей, добежала до станции и, промокшая, грязная, вернулась обратно. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Запятая перед второй частью двойного союза** — предложение 2:  
   «Н.М. Пржевальский ... путешествовал **не только** по Дальнему Востоку, **но и** по Центральной Азии.»  
   Двойной союз **не только ... но и**, запятая ставится перед второй частью (**но и**).  
   **А → 2**

2. **Б) Деепричастный оборот обособляется** — предложение 4:  
   «Оставшись один, Алексей ходил по комнате, браня себя вполголоса...»  
   Деепричастные обороты **оставшись один** и **браня себя вполголоса** выделяются запятыми.  
   **Б → 4**

3. **В) Сравнительный оборот обособляется** — предложение 1:  
   «по тёмной, **как чернила**, реке» — оборот **как чернила** является сравнительным и выделяется запятыми.  
   **В → 1**
