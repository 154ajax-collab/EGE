# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для приведённых пунктуационных правил. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Обстоятельство, выраженное деепричастным оборотом, обособляется. | 1) И сосновая аллея, уходящая вдаль, и старый дуб, раскинувший свои ветви над озером, — словом, всё здесь дышало покоем. |
| Б) Если первая и вторая части сложного бессоюзного предложения противопоставлены по смыслу, то между частями ставится тире. | 2) Пёс, взвизгнув, поджал хвост и, оглядываясь на хозяина, медленно побрёл к будке. |
| В) Согласованное приложение, стоящее после определяемого слова, обособляется (выделяется запятыми или тире). | 3) Вдалеке, на горизонте, уже виднелась полоса света — предвестник скорого рассвета. |
| | 4) Мать несколько раз дёрнула за ручку — дверь оказалась запертой изнутри. |
| | 5) И вдруг всё стихло — даже ветер утих, словно прислушиваясь к тишине. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Деепричастный оборот обособляется** — в предложении 2: «взвизгнув» (одиночное деепричастие) и «оглядываясь на хозяина» (деепричастный оборот) выделяются запятыми.  
   **А → 2**

2. **Б) Тире в бессоюзном предложении при противопоставлении** — предложение 4: «Мать несколько раз дёрнула за ручку — дверь оказалась запертой». Содержание частей противопоставлено (ожидание открытия / результат — заперто).  
   **Б → 4**

3. **В) Приложение после определяемого слова обособляется** — предложение 3: «полоса света — предвестник скорого рассвета» (приложение «предвестник» стоит после определяемого слова «полоса» и выделяется тире).  
   **В → 3**
