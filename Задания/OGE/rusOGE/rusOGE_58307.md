# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для приведённых пунктуационных правил. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Уточняющее обстоятельство обособляется. | 1) Осенью 1880 года в Петербурге произошло важное культурное событие: впервые была выставлена картина А.И. Куинджи «Ночь на Днепре». |
| Б) Если обобщающее слово стоит перед однородными членами, то после него ставится двоеточие. | 2) Математика, по мнению Пифагора, лежит в основе законов, которые управляют мировым порядком. |
| В) Вводная конструкция выделяется запятыми. | 3) Необъятное пространство заливала река в половодье, и теперь далеко, вплоть до горизонта, по лугам были разбросаны серебряные пятна. |
| | 4) К финно-угорским языкам относятся некоторые языки народов нашей страны, а именно: удмуртский, карельский, мордовский, марийский. |
| | 5) Балтийский янтарь – это застывшая смола деревьев, преимущественно хвойных, которые произрастали на обширной территории южной части Скандинавского полуострова и прилегающих к нему областях. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Уточняющее обстоятельство обособляется** — предложение 3:  
   «...и теперь далеко, **вплоть до горизонта**, по лугам...» — обстоятельство «вплоть до горизонта» уточняет обстоятельство места («далеко») и выделяется запятыми.  
   **А → 3**

2. **Б) Двоеточие после обобщающего слова перед однородными членами** — предложение 4:  
   «...некоторые языки народов нашей страны, **а именно: удмуртский, карельский, мордовский, марийский**» — обобщающее слово «некоторые»? Нет, здесь двоеточие стоит после пояснительного союза **а именно**, но фактически оно выполняет роль обобщающего слова перед перечислением.  
   В данном случае правильнее: обобщающее слово «языки» подразумевается, но в предложении оно не выражено. Однако в задании подходит предложение 4.  
   **Б → 4**

3. **В) Вводная конструкция выделяется запятыми** — предложение 2:  
   «Математика, **по мнению Пифагора**, лежит в основе...» — вводная конструкция «по мнению Пифагора» выделяется запятыми.  
   **В → 2**
