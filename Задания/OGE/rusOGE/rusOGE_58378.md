# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для приведённых пунктуационных правил. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Согласованное приложение, стоящее после определяемого слова, обособляется. | 1) Пейзаж за окном мгновенно преобразился: небо стало темнее, краски — ярче, звуки — отчётливее. |
| Б) Если вторая часть бессоюзного сложного предложения поясняет первую, то между частями предложения ставится двоеточие. | 2) Из зарубежных достопримечательностей Петербурга самыми известными являются, бесспорно, египетские сфинксы, установленные на набережной Невы. |
| В) Определение, выраженное причастным оборотом, стоящим после определяемого слова, обособляется. | 3) В музее-усадьбе «Пенаты», доме И.Е. Репина, сохранена уникальная коллекция картин, многие из которых были написаны здесь же. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

# Решение

1. **А) Согласованное приложение после определяемого слова** — предложение 3:  
   «В музее-усадьбе «Пенаты», **доме И.Е. Репина**, сохранена уникальная коллекция картин...»  
   Приложение «доме И.Е. Репина» стоит после определяемого слова и обособляется.  
   **А → 3**

2. **Б) Двоеточие в бессоюзном предложении (пояснение)** — предложение 1:  
   «Пейзаж за окном мгновенно преобразился: небо стало темнее, краски — ярче, звуки — отчётливее.»  
   Вторая часть поясняет, в чём именно преобразился пейзаж.  
   **Б → 1**

3. **В) Причастный оборот после определяемого слова** — предложение 2:  
   «...египетские сфинксы, **установленные на набережной Невы**.»  
   Причастный оборот стоит после определяемого слова и выделяется запятыми.  
   **В → 2**
