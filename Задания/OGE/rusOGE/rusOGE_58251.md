# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для приведённых пунктуационных правил. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Между частями сложноподчинённого предложения ставится запятая. | 1) Берёзовый лесок закончился, и перед путниками возникла речка, прячущаяся в камышовых зарослях. |
| Б) Обращение выделяется запятыми. | 2) Когда стало совсем жарко и толчея в порту замерла, друзья выбрались за городскую черту и поднялись на холм, с которого видна была гавань. |
| В) Согласованное приложение, стоящее после определяемого слова, обособляется. | 3) В это время Иван Езерский, мой сосед, вошёл в свой тесный кабинет. |
| | 4) В.И. Даля мы знаем как известного собирателя пословиц, как знатока русского языка. |
| | 5) И мы сохраним тебя, русская речь, великое русское слово. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Запятая между частями сложноподчинённого предложения** — предложение 2:  
   «Когда стало совсем жарко и толчея в порту замерла, друзья выбрались за городскую черту и поднялись на холм, с которого видна была гавань.»  
   Здесь есть придаточная часть (когда ... замерла) и придаточная определительная (с которого видна была гавань). Они выделяются запятыми.  
   **А → 2**

2. **Б) Обращение выделяется запятыми** — предложение 5:  
   «И мы сохраним тебя, русская речь, великое русское слово.»  
   Обращение «русская речь» обособляется запятыми.  
   **Б → 5**

3. **В) Согласованное приложение после определяемого слова** — предложение 3:  
   «Иван Езерский, мой сосед» — приложение «мой сосед» стоит после определяемого слова и выделяется запятыми.  
   **В → 3**
