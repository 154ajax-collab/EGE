# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для приведённых пунктуационных правил. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Если вторая часть бессоюзного сложного предложения обозначает причину, то между частями предложения ставится двоеточие. | 1) Путешественник стоял на палубе, вглядываясь в линию горизонта, и, судя по всему, не собирался покидать свой пост. |
| Б) Определение, выраженное причастным оборотом, стоящим после определяемого слова, обособляется. | 2) М.Ю. Лермонтов писал о Москве: «Москва не есть обыкновенный большой город, каких тысячи; Москва — не безмолвная громада камней холодных...». |
| В) Если вторая часть бессоюзного сложного предложения дополняет первую, то между частями предложения ставится двоеточие. | 3) Очертания скал, озарённых луной, начали проступать из темноты, отбрасывая длинные тени. |
| | 4) Я выглянул в окно: в утреннем тумане едва угадывались силуэты старых дубов. |
| | 5) Дети быстро разбежались по домам: надвигалась сильная гроза, и родители ждали их к ужину. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Двоеточие в бессоюзном предложении (причина)** — предложение 5:  
   «Дети быстро разбежались по домам: надвигалась сильная гроза, и родители ждали их к ужину.»  
   Вторая часть указывает причину (почему разбежались).  
   **А → 5**

2. **Б) Причастный оборот после определяемого слова** — предложение 3:  
   «Очертания скал, **озарённых луной**, начали проступать из темноты...»  
   Причастный оборот стоит после определяемого слова и выделяется запятыми.  
   **Б → 3**

3. **В) Двоеточие в бессоюзном предложении (дополнение)** — предложение 4:  
   «Я выглянул в окно: в утреннем тумане едва угадывались силуэты старых дубов.»  
   Вторая часть дополняет первую (что именно увидел).  
   **В → 4**
