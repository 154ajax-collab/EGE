# Задание

Установите соответствие между пунктуационными правилами и предложениями, которые могут служить примерами для приведённых пунктуационных правил. К каждой позиции первого столбца подберите соответствующую позицию из второго столбца.

| ПУНКТУАЦИОННЫЕ ПРАВИЛА | ПРЕДЛОЖЕНИЯ |
|------------------------|-------------|
| А) Между частями сложносочинённого предложения ставится запятая. | 1) Ирония Звягинцева, профессора нашего университета, не произвела, однако, на нового студента никакого впечатления. |
| Б) Согласованное приложение, стоящее после определяемого слова, обособляется. | 2) Вдалеке, на склоне горы, поросшей лесом, показался огонёк. |
| В) Если обобщающее слово стоит после однородных членов, то перед ним ставится тире. | 3) Хорошая книга – это ручеёк, по которому в человеческую душу втекает добро. |
| | 4) Между холмами мелькнуло море, однако дорога сразу же повернула вправо, и море исчезло из вида. |
| | 5) Перелёты через Северный полюс в Америку, рекорды дальности полёта, десятки новых самолётов, впервые поднятых в воздух, – всё это связано с именем прославленного лётчика Михаила Громова. |

Запишите в таблицу выбранные цифры под соответствующими буквами.

| А | Б | В |
|---|---|---|
|   |   |   |

---

# Решение

1. **А) Запятая между частями сложносочинённого предложения** — предложение 4: «Между холмами мелькнуло море, однако дорога сразу же повернула вправо, и море исчезло из вида.»  
   Здесь две грамматические основы (мелькнуло море; дорога повернула, море исчезло) соединены союзами **однако** и **и**.  
   **А → 4**

2. **Б) Согласованное приложение после определяемого слова** — предложение 1: «Ирония Звягинцева, профессора нашего университета, ...»  
   Слово «профессора» — приложение к «Звягинцева», стоит после определяемого слова и обособляется запятыми.  
   **Б → 1**

3. **В) Тире после однородных членов перед обобщающим словом** — предложение 5: «Перелёты ..., рекорды ..., десятки ..., – всё это ...»  
   Однородные члены стоят перед обобщающим словом «всё», поэтому перед ним ставится тире.  
   **В → 5**
